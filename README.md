# People + Places + Things

Photography portfolio and print shop for Blaine, a photographer based in Atlanta, GA.

A plain static site (HTML and CSS, no build step), published with GitHub Pages.

- `index.html`: Home
- `about.html`: About me
- `prints.html`: Prints for sale
- `styles.css`: all styling
- `images/`: hero, portrait, and print images (resized for the web)
