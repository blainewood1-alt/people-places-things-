# Blaine Wood Photo

People + Places + Things. Photography portfolio and print shop for Blaine, a photographer based in Atlanta, GA.

A static site published with GitHub Pages from the `main` branch. Any change merged to `main` goes live within a minute or two.

- Pages (`index.html`, `portfolio.html`, `prints.html`, `about.html`, `contact.html`) are generated by `tools/build_site.py`. Edit the lists in that script (and `tools/prints.json` for single prints), then run `python3 tools/build_site.py` to rebuild them.
- `tools/site.css` and `tools/site.js` are copied to the root by the build.
- `images/`: all photos, resized for the web.
